# NovelTie Arcade v2 design system (rules applied strictly)
1. One card component (.g). Same anatomy every time: art (4:3) / icon + name / one line / Play. Featured = same component, bigger grid cell. No chips, facts, notes, badges, legend.
2. Meaning comes from sections only: "Help build Similarize" (+ one sentence) and "Just for fun" (+ one sentence). No per-card tags; "Learn" dropped (all games teach).
3. Page = header (wordmark + one-line tagline) / featured section / fun section / footer (install + one line).
4. Type: Inter only (variable, opsz). Sizes: 13 / 15 / 17 / 22 / 28 / 40-56. Weights 400/500/600.
5. Spacing scale 4-8-12-16-24-40-64. Radii: card 16, art inherits, icon 10, button pill. Borders 1px hairline, no shadows.
6. Art: flat SVG, viewBox 400x300, deep game-specific bg, one lighter halo disc centered (family trait), motif in cream #F4EAD5 + one gold accent #F2C14E, no text, no gradients, centered within the disc.
